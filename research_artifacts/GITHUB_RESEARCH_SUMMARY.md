# GitHub research summary

This compact summary is suitable for a source repository. It contains protocol
descriptions, machine-readable population results, correction history,
statistics references, limitations, and reproducibility commands. It omits
the large raw-run tree and points to the local/archive evidence catalog instead.

The defensible contribution is an auditable measurement method that separates
fault exposure, service health, application progress, source drain, terminal
status, sink visibility, and typed full-row correctness. The evidence is not a
new recovery algorithm and does not support universal exactly-once or
performance-superiority language.

See:

- `MASTER_RESEARCH_RESULTS.csv` for one row per consolidated population.
- `MASTER_ATTEMPT_ACCOUNTING.csv` for denominators and negative outcomes.
- `EVIDENCE_CATALOG.csv` for claim-to-evidence mappings.
- `CORRECTION_SUPERSESSION_MAP.csv` for corrected interpretations.
- `SCIENTIFIC_LIMITATIONS.md` for unexecuted and unobservable scopes.
